# Huawei 2026 France Tech Arena - Future Network: data downloads

Download the training archives below.

| Dataset | Download |
| --- | --- |
| Labeled training data | [FutureNetwork-data-labeled.zip](https://dl.r0h.eu/techarena2026-paris/FutureNetwork-data-labeled.zip) |
| Unlabeled training data | [FutureNetwork-data-unlabeled.zip](https://dl.r0h.eu/techarena2026-paris/FutureNetwork-data-unlabeled.zip) |

Extract both archives into the same destination directory. They create separate
`labeled/` and `unlabeled/` folders automatically. See
`problem_statement.pdf` for the file layout and data format. The run command
for the Python example is at the top of `example.py`.
